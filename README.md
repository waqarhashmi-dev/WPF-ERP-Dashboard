# 🖥️ WPF ERP Dashboard

A clean, modern desktop dashboard application built using **WPF (.NET 8)** and the **MVVM design pattern**, designed to help businesses visualize key performance metrics and manage internal operations effectively.

---

## ✨ Project Overview

This ERP Dashboard is designed for **small to medium-sized businesses** to monitor sales, inventory, and performance KPIs through a sleek and responsive WPF interface.

It follows **best practices in MVVM architecture**, uses dependency injection, and is built with **.NET 8**, ensuring top-tier performance and maintainability.

---

## 🚀 Features

- 📊 Real-time dashboard layout
- 🧠 MVVM with CommunityToolkit.Mvvm
- ⚡ Async service structure ready
- 🎨 Clean UI with modern XAML styling
- 🛠️ .NET 8 compatibility and project structure
- 🧩 Ready for integration with database or APIs
